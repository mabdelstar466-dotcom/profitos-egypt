سياسة الخصوصية — GlowSignal

الحالة: هذه سياسة النسخة التجريبية (MVP) وليست بديلًا عن مراجعة قانونية قبل الإطلاق التجاري. لا تستخدم الخدمة لرفع بيانات حساسة أو بيانات شخصية غير ضرورية.

1. البيانات التي قد نعالجها

عند إنشاء حساب، تتم معالجة البريد الإلكتروني وبيانات المصادقة بواسطة Supabase Auth. وعند تسجيل الدخول ورفع ملفات CSV، قد تُحفظ في مساحة العمل بيانات تشغيلية مثل أسماء الحملات والإنفاق والظهور والنقرات والمحادثات، ومعرّفات عملاء وطلبات داخلية، وحالات العملاء والطلبات، والاعتراضات، وتسميات أعضاء فريق المبيعات، وأوقات الاستجابة، وقيم الطلبات والتكاليف التي أدخلتها.

2. أين تُحفظ البيانات؟

تُحفظ نسخة محلية في مساحة التخزين الخاصة بالمتصفح (localStorage) على الجهاز المستخدم. إذا سجلت الدخول ونجحت المزامنة، تُرسل البيانات التشغيلية المنظّمة إلى مشروع قاعدة بيانات Supabase المرتبط بالخدمة، وتُطبّق سياسات Row Level Security لعزل مساحات العمل. يستضيف GitHub Pages ملفات الموقع العامة. تخضع خدمات الأطراف الثالثة لشروطها وسياساتها الخاصة.

3. ما الذي يجب ألا ترفعه؟

لا ترفع أسماء العملاء أو أرقام هواتفهم أو عناوينهم أو أرقامهم القومية أو بيانات الدفع أو نصوص المحادثات أو أي معلومات صحية أو حساسة. استخدم معرّفات داخلية مستعارة لا تكشف هوية العميل. لا تضع كلمات المرور أو مفاتيح API السرية في ملفات CSV.

4. استخدام البيانات

تُستخدم البيانات التي تدخلها لحساب مؤشرات أداء الحملات وجودة العملاء والطلبات والتكاليف والتقارير داخل مساحة العمل. لا يدّعي GlowSignal أن النتائج تمثل حسابًا محاسبيًا أو ضريبيًا معتمدًا؛ وتعتمد دقتها على صحة واكتمال المدخلات.

5. التحكم والحذف

زر «مسح البيانات» داخل مساحة العمل يطلب استبدال بيانات الحملات والعملاء والطلبات في مساحة العمل الحالية ببيانات فارغة، إذا كان المستخدم مسجلًا وكانت المزامنة السحابية تعمل. كما يحذف النسخة المحلية الحالية من المتصفح. هذا الإجراء لا يحذف حساب المصادقة أو مساحة العمل نفسها. حذف بيانات المتصفح قد يزيل النسخة المحلية دون حذف النسخة السحابية.

6. المدفوعات والتكاملات

لا توجد حاليًا اشتراكات مدفوعة أو بوابة دفع أو ربط مباشر مفعّل مع Meta أو TikTok أو WhatsApp. لا ترسل أموالًا ولا تشارك رموز وصول خارجية بناءً على صفحات النسخة التجريبية.

7. الأمان والحدود

تستخدم الواجهة مفتاح Supabase Publishable Key المخصص للاستخدام العام مع سياسات قاعدة البيانات. لا ينبغي وضع Service Role Key أو أي سر إداري في ملفات الموقع العامة. لا توجد في هذه النسخة وعود بتوافر دائم أو نسخ احتياطي مستقل مضمون؛ احتفظ بنسخ آمنة من ملفاتك الأصلية.

8. التحديثات

قد تتغير هذه السياسة مع تطور الخدمة. راجع هذه الصفحة قبل استخدام إصدار جديد أو إدخال أنواع إضافية من البيانات.
