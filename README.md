# ProfitOS Egypt

موقع عربي لحساب صافي أرباح المتاجر الإلكترونية، مع حاسبة مجانية ومقالات تعليمية.

## الحالة
- ملفات الموقع مرفوعة على فرع main.
- أضفنا GitHub Actions workflow للنشر التلقائي إلى GitHub Pages في `.github/workflows/deploy-pages.yml`.
- **لا نفترض أن الموقع منشور** قبل نجاح workflow وتأكيد الرابط العام.
- رابط الموقع المتوقع عند نجاح النشر: https://mabdelstar466-dotcom.github.io/profitos-egypt/
- سجل عمليات النشر: https://github.com/mabdelstar466-dotcom/profitos-egypt/actions
- لو تعذّر تمكين GitHub Pages تلقائيًا، يلزم تفعيل GitHub Pages من Settings → Pages وتحديد GitHub Actions كمصدر للنشر.

## الخصوصية
الحاسبة تعمل داخل المتصفح ولا ترسل الأرقام إلى أي سيرفر. لا تضع ملفات المنتج المدفوع في المستودع العام.

## حالة البيع
ملف Excel المدفوع **غير موجود في المستودع**. الدفع والتسليم التلقائي غير مفعّلين بعد. الحاسبة تقديرية وليست نصيحة محاسبية أو ضريبية.
