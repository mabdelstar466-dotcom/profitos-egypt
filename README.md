# ProfitOS Egypt

موقع عربي مجاني لحساب ربح المتاجر الإلكترونية مع مقالات تعليمية. الحاسبة تعمل داخل المتصفح ولا تخزن المدخلات.

## نشر الموقع
من Settings → Pages → Build and deployment اختر Deploy from a branch ثم main و / (root) ثم Save. الرابط المتوقع بعد النشر: https://mabdelstar466-dotcom.github.io/profitos-egypt/ (يجب التأكد من تفعيل Pages أولًا).

## مهم
ملف Excel المدفوع **غير موجود** في المستودع العام. الدفع والتسليم لم يُفعّلا بعد. الأرقام تقديرية وليست نصيحة محاسبية أو ضريبية.
