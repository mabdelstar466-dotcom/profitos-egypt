# GlowSignal

نظام تحليلي تجريبي لبراندات التجميل والعناية بالشعر، يربط الإنفاق الإعلاني بجودة العملاء والطلبات المُسلّمة.

## الحالة الحالية: MVP 0.2
- مساحة عمل فعلية لاستيراد ملفين CSV (الحملات، والعملاء والطلبات).
- حساب الإنفاق، العملاء الفريدين، التأهيل، الطلبات المُسلّمة، الإيراد، التكاليف المسجلة، ومساهمة تقديرية بعد الإعلان.
- مقارنة الحملات بعد تجميع الصفوف اليومية حسب اسم الحملة.
- تحليل الاعتراضات ومؤشرات فريق المبيعات.
- حفظ محلي في متصفح المستخدم باستخدام localStorage.
- تحميل نماذج CSV وبيانات تجريبية وتصدير ملخص النتائج.
- لا يوجد بعد تسجيل دخول، قاعدة بيانات سحابية، مزامنة بين الأجهزة، اشتراك مدفوع، أو تكامل مباشر مع Meta / WhatsApp / TikTok.

## طريقة الاستخدام
1. افتح مساحة العمل.
2. نزّل نموذج الحملات ونموذج العملاء والطلبات.
3. استبدل بيانات المثال ببياناتك المجهولة الهوية، أو صدّر تقاريرك إلى CSV بنفس الأعمدة.
4. ارفع الملفين كلٌّ في مكانه.
5. راجع لوحة التحليل والحملات والاعتراضات وفريق المبيعات.
6. البيانات محفوظة على نفس المتصفح والجهاز فقط. امسحها من زر "مسح البيانات" عند الحاجة.

## خصوصية وحدود
- لا ترفع أسماء أو أرقام هواتف أو عناوين أو نصوص محادثات العملاء. استخدم معرّفات داخلية مجهولة.
- الملفات تُعالج داخل المتصفح ولا تُرسل إلى خادم في الإصدار الحالي.
- "صافي المساهمة التقديري" ليس صافي ربح محاسبيًا؛ لا يشمل المصاريف العامة أو الرواتب أو الضرائب أو أي تكلفة لم تُسجل.
- إسناد الحملات يتم بمطابقة اسم الحملة حرفيًا بعد إزالة المسافات واختلاف حالة الأحرف؛ ليس نموذج attribution متعدد اللمسات.
- حفظ المتصفح ليس بديلًا عن قاعدة بيانات ونسخ احتياطي.

## خارطة الطريق
1. تجربة مع 3–5 براندات ببيانات CSV مجهولة الهوية والتحقق من استعدادها للدفع.
2. إنشاء Supabase Auth + Postgres مع عزل بيانات كل مساحة عمل بسياسات Row Level Security.
3. إضافة ربط Meta الرسمي بعد إنشاء تطبيق مطور واستكمال الصلاحيات ومراجعة Meta المطلوبة.
4. إضافة WhatsApp Business Platform عند توفر موافقات واشتراطات الاستخدام.
5. ربط TikTok بعد إنشاء تطبيق المطور والحصول على الموافقات المطلوبة.
6. تفعيل الاشتراكات بعد اختيار مزود دفع مناسب للسوق المصري والتحقق من متطلباته.
