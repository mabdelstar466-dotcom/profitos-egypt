# GlowSignal

منصة SaaS تجريبية لتحليل نمو براندات التجميل والعناية بالشعر، تربط الإنفاق الإعلاني بجودة العملاء والطلبات المُسلّمة والتكاليف المسجلة.

## الحالة الحالية: Cloud MVP 0.4

### يعمل في النسخة الحالية
- موقع تعريفي عام ومساحة عمل عربية متجاوبة.
- تحليل ملفات CSV للحملات والعملاء والطلبات.
- مؤشرات الإنفاق، العملاء الفريدين، التأهيل، التسليم، الإيراد، التكاليف المسجلة، ROAS، CTR، وتكلفة العميل والمؤهل والطلب المُسلّم.
- مساهمة تقديرية على مستوى المتجر والحملة بعد التكاليف المسجلة.
- مراجعة أسماء الحملات غير المتطابقة والصفوف المكررة.
- تسجيل حساب بالبريد وكلمة المرور، ورابط دخول بالبريد، وتسجيل الدخول، وإعادة تعيين كلمة المرور عبر Supabase Auth.
- مساحة عمل خاصة لكل حساب، وحفظ سحابي عبر Supabase Postgres عند اكتمال إعداد قاعدة البيانات.
- سياسات Row Level Security لعزل بيانات مساحات العمل.
- حفظ محلي احتياطي، وتنزيل واستعادة نسخة JSON كاملة، وتصدير تقرير أداء الحملات إلى CSV.

### ما لا يزال غير متاح
- لم يتم تفعيل الاشتراكات أو تحصيل المدفوعات.
- لا يوجد OAuth أو سحب مباشر لبيانات Meta Ads أو TikTok Ads.
- لا يوجد تكامل WhatsApp Business Platform أو استيراد تلقائي من شركات الشحن.
- لا يوجد نظام دعوات أعضاء متكامل أو إدارة أدوار من الواجهة.
- لا تعتبر النسخة جاهزة بعد لاستقبال بيانات شخصية أو عملاء يدفعون قبل اختبار Supabase وRLS والنسخ الاحتياطي ومراجعة الأمان.

## إعداد Supabase لمرة واحدة
1. افتح مشروع Supabase المرتبط بالموقع.
2. افتح SQL Editor.
3. انسخ ملف supabase/schema.sql كاملًا والصقه ثم اضغط Run. الملف قابل لإعادة التشغيل.
4. من Authentication → URL Configuration:
   - Site URL: https://mabdelstar466-dotcom.github.io/profitos-egypt/
   - Redirect URL: https://mabdelstar466-dotcom.github.io/profitos-egypt/**
5. تأكد من تفعيل Email provider. إذا لم تصل الرسائل، راجع إعداد SMTP وحدود الإرسال في Supabase.
6. افتح مساحة العمل واضغط «اختبار الاتصال»، ثم أنشئ الحساب وأكّد البريد إذا طُلب ذلك.
7. ارفع ملفات CSV بعد إزالة البيانات الشخصية.

## تنسيق ملفات CSV

### الحملات
الحقول المطلوبة: campaign_name (أو Campaign name)، spend (أو Amount spent)
اختيارية: date / Reporting starts، impressions، clicks / Link clicks، messages / Messaging conversations started.

### العملاء والطلبات
الحقول المطلوبة: lead_id, campaign_name
اختيارية: created_at, lead_status, objection, agent, first_response_minutes, order_id, order_status, order_value, product_cost, shipping_cost, return_cost, payment_fees.

استخدم معرّفات داخلية مستعارة. لا ترفع أسماء أو أرقام هواتف أو عناوين أو نصوص محادثات العملاء.

## تعريف المؤشرات وحدودها
المساهمة التقديرية = إيراد الطلبات المُسلّمة − تكلفة منتجاتها − الشحن المسجل للطلبات التي خرجت للشحن − تكاليف المرتجعات المسجلة − رسوم الدفع المسجلة − الإنفاق الإعلاني.

هذا ليس صافي ربح محاسبيًا؛ لا يشمل المصاريف العامة والرواتب والضرائب والخصومات والتكاليف غير المسجلة. ROAS هنا يستخدم الإيراد المُسلّم ÷ الإنفاق، وليس قيمة الطلبات التي لم تُسلّم. مطابقة الحملة تتم باسم الحملة بعد إزالة المسافات الزائدة وتوحيد حالة الأحرف، وليست إسنادًا متعدد اللمسات.

## الأمان والخصوصية
- المفتاح في الواجهة هو Supabase Publishable Key فقط. لا تضع Service Role Key أو أي سر في ملفات الموقع.
- RLS هو خط الدفاع الأساسي لعزل بيانات كل مساحة عمل؛ يجب اختباره بحسابين منفصلين قبل الإطلاق.
- سياسة الخصوصية: glowsignal-privacy.html.
- شروط الاستخدام: glowsignal-terms.html.
- لا ترفع بيانات شخصية أو حساسة.

7. إضافة نسخ احتياطي واستعادة ومراقبة أخطاء ومراجعة أمنية.
