# ProfitOS Egypt

موقع عربي مجاني لتقدير ربحية المتاجر الإلكترونية في مصر، مع حاسبة داخل المتصفح ومقالات تعليمية وصفحة تعريف بالمنتج الكامل.

## الحالة الحالية
- الموقع يحتوي على حاسبة مجانية تعمل داخل المتصفح.
- صفحة المنتج تشرح ProfitOS Egypt V3: ملف Excel عربي لإدارة المنتجات والطلبات ولوحة التحكم والتسعير.
- النسخة المدفوعة وملف Excel الكامل ودليل الاستخدام محفوظة خارج المستودع العام؛ لا ترفع ملفات المنتج المدفوع هنا.
- السعر المقترح للاختبار: 399 جنيه مصري، ولم يثبت قبوله من السوق.
- الشراء والدفع والتسليم الرقمي غير مفعّلة حتى اكتمال الاختبار.

## حدود المنتج
- إدخال البيانات يدوي في Excel؛ لا يوجد ربط تلقائي مع Meta Ads أو TikTok Ads أو EasyOrders أو بوابات الدفع.
- الحاسبة لا ترسل مدخلات المستخدم إلى خادم في النسخة الحالية.
- النتائج تقديرية ولا تشمل الضرائب أو أي تكلفة لم يُدخلها المستخدم.

## النشر
ملفات الموقع على فرع main، ويوجد GitHub Actions workflow للنشر إلى GitHub Pages. تحقق من نجاح آخر تشغيل قبل اعتبار أي تحديث منشورًا.
